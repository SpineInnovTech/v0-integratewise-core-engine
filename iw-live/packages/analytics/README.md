# @integratewise/analytics

Cross-platform analytics for IntegrateWise (Amplitude, Mixpanel, PostHog, console provider).

**Status:** No app or service in the workspace currently depends on this package. The main web app (`apps/web`) does not list it; references exist only in `apps/web/src.bak/`. To wire it, add `"@integratewise/analytics": "workspace:*"` to the consuming app and use the exported providers and hooks.

See [docs/WORKSPACE_AUDIT_ORPHANS.md](../../docs/WORKSPACE_AUDIT_ORPHANS.md) for repo-wide orphan audit.
