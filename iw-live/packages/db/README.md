# @integratewise/db

Shared Supabase database connector for IntegrateWise services.

**Status:** No workspace package currently depends on this package. Services use `@supabase/supabase-js` directly or internal helpers. To use this package, add `"@integratewise/db": "workspace:*"` to your app or service and use `createDbClient()` (preferred over deprecated `createDb()`).

See [docs/WORKSPACE_AUDIT_ORPHANS.md](../../docs/WORKSPACE_AUDIT_ORPHANS.md) for repo-wide orphan audit.
