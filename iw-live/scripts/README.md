# Scripts (kept only needed)

Run from **repo root**.

| Script                              | Purpose                                                                                                                                                                                                                                                            |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **cloudflare-deploy-worker.sh**     | Deploy a single Worker (`./scripts/cloudflare-deploy-worker.sh gateway production`)                                                                                                                                                                                |
| **deploy-all-workers.sh**           | Deploy all Workers (or one) — no Doppler. For CI or local: `./scripts/deploy-all-workers.sh production` or `./scripts/deploy-all-workers.sh production gateway`. Order: pipeline → connector → mcp-connector → intelligence → knowledge → workflow → l2 → gateway. |
| **cloudflare-deploy.sh**            | Deploy by target (frontend / workers / all) and environment (uses Doppler for frontend)                                                                                                                                                                            |
| **deploy-production.sh**            | Full production deploy (frontend + workers, options)                                                                                                                                                                                                               |
| **ensure-pnpm.sh**                  | Ensure pnpm is available via Corepack (`pnpm run ensure-pnpm`)                                                                                                                                                                                                     |
| **rotate-secrets.sh**               | Rotate and sync secrets (Doppler/Cloudflare)                                                                                                                                                                                                                       |
| **setup-secrets.sh**                | First-time or env secrets setup (staging/production)                                                                                                                                                                                                               |
| **export-neon-schema.sh**           | Export Neon schema (DDL only) for Neon → Supabase migration. Set `NEON_DATABASE_URL` or `DATABASE_URL`, then `./scripts/export-neon-schema.sh`. Output: `scripts/neon-schema-export.sql` (gitignored). See docs/NEON_TO_SUPABASE_MIGRATION.md.                     |
| **run-adaptive-spine-migration.sh** | Run Adaptive Spine 12×11 migration (055): set `SUPABASE_DB_URL` then `./scripts/run-adaptive-spine-migration.sh`, or `npx supabase link` + `npx supabase db push`                                                                                                  |
| **setup-supabase.sh**               | Supabase project setup: connection check, migrations, seed, verify                                                                                                                                                                                                 |
| **sync-doppler-to-workers.sh**      | Sync Doppler secrets to Cloudflare Workers                                                                                                                                                                                                                         |
| **validate-cloudflare-config.sh**   | Validate wrangler/Cloudflare config before deploy                                                                                                                                                                                                                  |
| **verify-deployment.sh**            | Post-deploy verification (optional BASE_URL)                                                                                                                                                                                                                       |
| **verify-l2-happy-path.sh**         | L2 slice end-to-end verification                                                                                                                                                                                                                                   |

Empty folders `deployment/` and `operations/` are left in place; add new scripts there if needed.
