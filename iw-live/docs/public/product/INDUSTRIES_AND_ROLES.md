## The Adaptive Point

The system doesn't have 12 different products for 12 departments. It has one product with one Spine that adapts:

- **Schema adapts** — department + industry selection at onboarding shapes what data enters
- **Connectors adapt** — different industries connect different tools
- **Workspace adapts** — views render based on what the Spine holds for that schema
- **Twin adapts** — insights are contextual to the industry and role

A SaaS CSM and a CA and a hotel manager all use the same system. They see different things because their Spine holds different data, shaped by different schemas, fed by different connectors. The Twin reasons over whatever is there.

Same Adaptive Spine. Same User Workbench substrate. Same Twin Workbench. Different projection and lens.
