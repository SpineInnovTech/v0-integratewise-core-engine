- **8-Stage Pipeline**: Analyze → Classify → Filter → Refine → Extract → Validate → Sanity → Sectorize. S7.5 Identity Resolution.

- **Security**: Tenant isolation (RLS). OAuth 2.0 + PKCE. Token encryption. Govern gate. Full audit trail.
