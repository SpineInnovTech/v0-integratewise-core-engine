THE COMPANY DESCRIPTION

One line:
IntegrateWise is the continuity layer for the AI era.

Long form:
IntegrateWise is the continuity layer for the AI era —
connecting systems through a shared protocol, preserving
organizational memory in a unified Spine, and governing how
intelligence reasons and acts across tools, models, and time.

PART 2 — THE ROOT CAUSE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Modern software was built for transactions.
Organizations operate on continuity.

Transactions record what happened.
Continuity preserves why it happened, what it means,
and how it should influence every future decision.

As organizations adopt more tools and more AI,
continuity breaks:

Context fragments.
Memory disappears.
Knowledge decays.
Decisions lose lineage.
Humans become translators between systems.

IntegrateWise exists to restore continuity.

PART 4 — THE ARCHITECTURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Three layers. Each necessary. None sufficient alone.

LAYER 1 — PROTOCOL (MCP)
Purpose: How everything connects.
Solves: Discovery, invocation, standardization,
agent-to-agent communication, ecosystem reach.
MCP is the language.
Gets stronger as MCP ecosystem adoption increases.

LAYER 2 — MEMORY (Spine)
Purpose: What everything remembers.
Solves: Context, continuity, organizational memory,
entity identity, knowledge persistence.
Spine is the memory.
Model-independent. Survives tool changes.
Survives provider changes. Survives team changes.

LAYER 3 — INTELLIGENCE (Agents)
Purpose: What everything understands.
Agents: Twin · Signal Engine · Triage Bot · Operator · Maintainer
Solves: Reasoning, governance, monitoring,
proposals, execution, preservation.
No Python. No DataWeave. No generated transformation code.
LLM tokens are reserved for reasoning only.
Deterministic work is handled deterministically.

PART 6 — THE THREE ENGINES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

THE FACE: Twin (conversation, presentation, action)
THE BRAIN: Three Engines (classification, governance, monitoring)
THE BODY: Spine (structure, memory, relationships)

Engine 1 — The Normalizer
WHEN: On arrival — every piece of data that enters
WHAT: Classifies · Links · Extracts · Files · Triggers
DOCTRINE: Semantic Contract (Law 2)
All data passes through. No exceptions.

Engine 2 — The Triage Bot
WHEN: On every write — nothing enters Spine without passing through
WHAT: Deduplicates · Conflict-checks · Scores · Routes · Records lineage
ROUTING:
HIGH confidence → auto-approve → write to Spine
MEDIUM → route to human review
LOW → reject or ask for clarification
DOCTRINE: Governance (Law 5) + Lineage (Law 7)
Human reviews ~20% of writes. 80% flows automatically.

Engine 3 — The Signal Engine
WHEN: Continuously — always watching
WHAT: Monitors every entity · Detects deviation ·
Classifies urgency · Surfaces to Twin
DOCTRINE: Pattern Detection + Drift Detection
Not reactive. Proactive. Always on.

PART 7 — THE TWO INGESTION PATHS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Path 1 — MCP Path (speaks MCP natively)
App → MCP Gateway → Validation → Resolver → Spine

Path 2 — Connector Path (API wrapper)
App → Connector → Loader → Normalizer → Resolver → Spine

Both paths converge at the Resolver.
Both paths lead to one destination: the Spine.
The path an app takes does not matter to the rest of the system.

PART 9 — THE SEVEN LAWS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

LAW 0 — PRIMACY
The human is the authority. The system serves human intent.
Never replaces human judgment.

LAW 1 — PROTOCOL
Every agent connects through the Protocol Gateway.
No agent connects directly to an external tool.

LAW 2 — SEMANTIC
Every piece of data that enters the Spine passes
through the Normalizer. No raw, unnormalized writes.

LAW 3 — CONTINUITY
Every agent reads from the Spine first.
No agent reads directly from an external tool
when the Spine has the data.

LAW 4 — CAPABILITY
Every agent thinks in capabilities, not tools.
Create a ticket. Send a message. Update a record.
The tools change. The capabilities stay.

LAW 5 — GOVERNANCE
AI proposes. Human approves. Operator executes.
Nothing runs without human approval.

LAW 6 — MEMORY
The human's context is permanent.
Not dependent on model, provider, or session.

LAW 7 — LINEAGE
Every action, every decision, every execution is traceable.
Accountability serves authority.
