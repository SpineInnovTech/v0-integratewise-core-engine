The platform repo `integratewise-live` (private GitHub `NirmalPrinceJ/integratewise-live`; Cloudflare Workers + Bun + Turbo monorepo) owns all truth. This repo (iwa-customer-zero) is its frontend client. Contract verified from source June 2026 — trust this over the FRONTEND Figma export's `plans/architecture.md` AND over `replit.md`; both are stale on auth.

- Gateway worker `services/gateway` is the only frontend-reachable ingress. Base URL: prod `https://gateway.integratewise.ai`, dev `https://gateway.dev.integratewise.ai`, local `http://localhost:8786`. Routes proxy by path prefix to internal services via CF service bindings: `/api/v1/auth/*`, `/api/v1/workspace/*` (BFF: dashboard, nav, views, verification), `/api/v1/cognitive/twin`, `/api/v1/intelligence/*` (signals, proposals), `/api/v1/projections/*` (entity360, morning-context), `/api/v1/billing/*`, `/api/v1/pipeline/*` (spine entities), `/api/v1/knowledge/*`.
- AUTH IS CUSTOM, NOT CLERK. Gateway issues RS256 JWT (`/api/v1/auth/login|signup|me`). Frontend sends `Authorization: Bearer <jwt>` + `x-tenant-id: <uuid>`. iss `auth.integratewise.ai`, aud `app.integratewise.ai`. Client stores JWT in localStorage `iw_at`, silent-refresh on load, validates against `/api/v1/auth/me`.
- An existing real client already lives at `apps/web` in the platform repo: `src/lib/gateway-client.ts` (GatewayHttpClient: header injection, 401-refresh, 429 retry-after, 5xx backoff, offline GET queue), `src/lib/api-client.ts` (domain route fns: workspace/pipeline/connector/intelligence/billing/admin), `src/hooks/use-api.ts` (TanStack Query hooks), `src/lib/auth-manager.ts`, `src/components/core/auth/login-page.tsx`. Stack: React 18.3, Vite 6, react-router 7, TanStack Query 5, Tailwind 4, Radix, Framer Motion. Env: `VITE_API_BASE_URL`, `VITE_AUTH_URL`, `VITE_SPINE_PROVIDER` (`gateway-proxy` | `local-mock`). apps/web also has a mature admin surface (IAM/tenancy/roles/audit/governance) + `customer-zero-verification.tsx`.
- Multi-tenant: every table has `tenant_id`. Platform "god view" / super_admin = the special tenant id `iw-customer-zero`. Truth migrating Supabase -> Cloudflare D1. Billing = Razorpay (HMAC `x-razorpay-signature` webhooks); tables `payment_transactions`/`subscriptions`/`usage_records`.

**Why:** the Figma export's architecture.md claims Clerk auth and a different `/api/v1/*` endpoint list; the real gateway uses custom JWT and different route groups. Building to the doc yields a frontend that cannot talk to the real backend.
**How to apply:** when wiring this repo's frontend to real data, mirror apps/web's gateway-client/auth-manager/use-api against the routes above; do NOT implement Clerk; target `VITE_API_BASE_URL` (gateway dev URL) with the local api-server relay as fallback. To re-read the platform repo: GitHub is connected — clone via the connectors token to `/tmp` (never into this repo; preserve the two-repo separation).
