# IntegrateWise Spine Schema — GTM Entities
**Version:** 1.0  
**Scope:** Lead · Campaign · Pipeline · Deal  
**Layer:** Canonical Spine (post-ingestion, tool-agnostic)

---

## Design Rules

- Every entity is **tool-agnostic** at the Spine layer. Apollo `person` and HubSpot `contact` both collapse into `Lead`.
- `_spine` block is **mandatory** on every entity — this is what makes it a Spine record, not just a DB row.
- `_sources[]` tracks provenance per field. The Spine does not overwrite — it merges with confidence scoring.
- No agent writes directly to Spine. All writes go through `memory.propose` → Governance → approval.
- Foreign keys reference Spine entity IDs, not tool-native IDs.

---

## 1. Lead

The canonical representation of a person showing intent or in active qualification.

```json
{
  "id": "uuid",
  "entity_type": "lead",

  // Identity
  "full_name": "string",
  "email": "string",
  "phone": "string | null",
  "linkedin_url": "string | null",
  "title": "string | null",

  // Company linkage
  "company_name": "string",
  "company_id": "ref → Company",

  // Qualification
  "status": "enum: new | contacted | qualified | disqualified | converted",
  "score": "int 0–100",
  "icp_fit": "enum: strong | moderate | weak | unknown",

  // Attribution
  "source": "enum: organic | paid | referral | outbound | event | partner | import",
  "source_tool": "enum: apollo | hubspot | salesforce | manual | linkedin",
  "campaign_id": "ref → Campaign | null",

  // Ownership & routing
  "owner_id": "ref → User",
  "pipeline_id": "ref → Pipeline | null",
  "deal_id": "ref → Deal | null",

  // Engagement
  "last_activity_at": "datetime | null",
  "last_contacted_at": "datetime | null",
  "converted_at": "datetime | null",
  "disqualified_reason": "string | null",

  // Metadata
  "tags": "string[]",
  "notes": "text | null",
  "created_at": "datetime",
  "updated_at": "datetime",

  // IW Spine Block
  "_spine": {
    "confidence_score": "float 0.0–1.0",
    "approval_state": "enum: auto_approved | pending_review | rejected",
    "memory_refs": "string[]",
    "last_proposed_by": "agent_id | user_id",
    "sources": [
      {
        "tool": "apollo | hubspot | salesforce | manual",
        "external_id": "string",
        "last_synced": "datetime",
        "fields_owned": "string[]"
      }
    ]
  }
}
```

**Source Mappings**

| Spine Field       | Apollo          | HubSpot          | Salesforce       |
|-------------------|-----------------|------------------|------------------|
| `full_name`       | `first_name` + `last_name` | `firstname` + `lastname` | `Name`  |
| `email`           | `email`         | `email`          | `Email`          |
| `title`           | `title`         | `jobtitle`       | `Title`          |
| `company_name`    | `organization.name` | `company`    | `Company`        |
| `status`          | `contact_stage` | `lifecyclestage` | `LeadStatus`     |
| `score`           | `contact_score` | `hubspotscore`   | `Lead_Score__c`  |
| `source`          | `source`        | `hs_lead_source` | `LeadSource`     |

  "name": "string",

  // Stage definition
  "stages": [
    {
      "id": "uuid",
      "name": "string",
      "order": "int",
      "probability": "float 0.0–1.0",
      "is_won": "boolean",
      "is_lost": "boolean",
      "required_actions": "string[]",
      "avg_days_in_stage": "float | null"

  ],

  // Financial

  // Ownership
  "owner_id": "ref → User",
  "team_ids": "ref[] → User",

  // Attribution
  "source_tool": "enum: hubspot | salesforce | linear | manual",
  "external_pipeline_id": "string | null",

  // Metadata
  "tags": "string[]",
  "created_at": "datetime",
  "updated_at": "datetime",

  // IW Spine Block
  "_spine": {
    "confidence_score": "float 0.0–1.0",
    "approval_state": "enum: auto_approved | pending_review | rejected",
    "memory_refs": "string[]",
    "last_proposed_by": "agent_id | user_id",
    "sources": [
      {
        "tool": "hubspot | salesforce | manual",
        "external_id": "string",

**Default Stage Templates**

| Pipeline Type     | Stages                                                           |
|-------------------|------------------------------------------------------------------|
| `sales`           | New Lead → Qualified → Demo → Proposal → Negotiation → Won/Lost |
| `partnership`     | Identified → Outreach → Intro → Evaluation → Agreement → Active |
| `investor`        | Identified → Warm → Intro → DD → Term Sheet → Closed            |
| `customer_success`| Onboarding → Adoption → Expansion → Renewal → Churned           |

## Governance Thresholds (inherited from Spine)

| Score Range | Action              | Example Trigger                        |
|-------------|---------------------|----------------------------------------|
| ≥ 0.85      | Auto-approve        | Apollo enrichment of known company     |
| 0.60–0.84   | HITL review         | Score change, stage move, new lead     |
| < 0.60      | Reject / flag       | Conflicting source data, low confidence|

## IW-Ops Usage Notes

For Customer Zero (IW-Ops), the tool-to-entity mappings are:

| Business Intent       | Source Tool  | Spine Entity |
|-----------------------|--------------|--------------|
| Find a prospect       | Apollo       | Lead         |
| Run an outreach       | Apollo Seq   | Campaign     |
| Track a deal          | HubSpot/Manual | Deal       |
| Monitor the funnel    | —            | Pipeline     |
| Enrich company data   | Apollo       | Company      |

ADK never calls Apollo directly. It calls `find_lead`, `get_deal`, `check_pipeline` — and routes through the MCP pool to the right source.
