## 3. Marketplace: master listing → field‑safe variants

Your master listing is good; now, think in terms of constrained fields each marketplace will ask for. [developers.openai](https://developers.openai.com/apps-sdk/deploy/submission)

General “field set” you should assume:

- App name (40–60 chars safe).
- Short tagline (80–100 chars).
- One‑line short description (max ~120 chars).
- Long description (markdown or plain, often 400–800 chars; some allow more).
- “What it does” bullet list.
- “Best for / use cases” bullets.
- CTA or “how to get started” line.
- Logo + optional banner.
- Privacy policy URL, docs URL, support URL.

Your master text already covers each:

- Name → “IntegrateWise Continuity Bridge”.
- Tagline → “One connection. Shared context everywhere.”
- Short description → you already have a good one.
- Full description → your existing “IntegrateWise Continuity Bridge is the continuity layer…” block.
- What it does → your “What it does” section is plug‑and‑play as bullets.
- Use it when → your “Use it when you want to:” bullets.
