Structure
• Uses the standard mcpServers format (works with Cursor, Kiro, VS Code, Codex, etc.).
• The two IntegrateWise entries are explicitly tied to the integratewise tenant via the bridge (using existing client IDs kiro-iw / cursor-iw that are already registered in your D1).
• All the high-value external MCP tools discovered across your configs (Kiro powers, Cursor global, VS Code Insiders, project overrides, etc.) are included as additional tools in the same pool.
• mcpflare (your local aggregator) is also in the list so you can optionally route many of them through a single connection if desired.

How to use it

As a master / global config:

# Cursor
cp /Users/nirmal/Github/integratewise-live/mcp-pool.json ~/.cursor/mcp.json

# Or for Kiro (merge or replace the mcpServers section)
cp /Users/nirmal/Github/integratewise-live/mcp-pool.json ~/.kiro/settings/mcp.json

Project-local (in integratewise-live): The existing .cursor/mcp.json and .vscode/mcp.json can be replaced or symlinked to this file (adjust the bridge args to relative scripts/... if you prefer that style inside the repo).

For other tenants (e.g. customers): Duplicate the two integratewise* entries, change INTEGRATEWISE_TENANT_ID + INTEGRATEWISE_CLIENT_ID, and register the client (see scripts/register-oauth-client.ts or the SQL in your D1).
